OpenFacet
v1.1  ·  Panel Layout, A3 Drawings & BOM Tool

OpenFacet is a browser-based panel design tool for electronics enclosures. Design drill patterns, cutouts and mounting layouts on any panel face, then take that design straight through to production: DXF for CNC, a fully dimensioned A3 drawing sheet for the shop floor, and a bill of materials for purchasing.

Runs entirely offline — no server, no signup, no data sent anywhere. Open the HTML file and start designing. (The one exception is the optional Excel BOM export, which loads a small spreadsheet library from a CDN the first time you use it — every other feature works with no internet connection.)

Design

  • Enclosure library — Hammond 1590, 1455, EIA-310 rack panels, custom
  • Component library — BNC, XLR, IEC, D-Sub, USB, pots, switches, rivnuts, DIN rail
  • Shape types — Circle, hole, rivnut, rect, rounded rect, slot, D-cut, double D-cut, compound
  • Custom components — add any shape from a datasheet, save as JSON library
  • Light / dark theme — light mode for print comparison
  • Touch & mobile support — responsive layout with a Library / Canvas / Properties tab switcher on phones and small screens

Output

  • DXF export — R12 compatible, layered (OUTLINE / CUTOUT / HOLE / RIVNUT / MOUNTING / DIM / REFERENCE)
  • A3 print sheet — red ASME-style title block, per-inch zone lettering/numbering, overall and per-feature dimensioning, units in mm or inches
  • Feature detail drawings — enlarged, dimensioned "how to cut it" views for D-cuts, double D-cuts and compound connectors, with lettered balloons linking back to the panel
  • Bill of materials — printable BOM and one-click .xlsx export, matching connectors to the component library and auto-adding screw/nut/washer lines (or a screw only, for rivnuts) for every mounting hole
  • Project save/load — full design state as JSON

Standards

  • DXF: AutoCAD R12 (AC1009) — opens in FreeCAD, QCAD, LibreCAD, AutoCAD
  • Rack panels: EIA-310-D / IEC 60297-3
  • BNC cutout: MIL-STD D-cut Ø9.7mm / 8.7mm flat
  • Banana socket: Ø8.33mm double D-cut / WAF 6.35mm
  • DIN rail: EN 60715 35mm slot pattern
  • Drawing sheet: ISO A3, tolerance block and zone lettering styled after ASME Y14.1
How to Add a Custom Shape Component
Step-by-step guide — from datasheet to placed cutout

When do you need a custom shape?

Use a custom component when your connector or hardware isn't in the built-in library, or when it needs a non-standard cutout — e.g. an unusual panel-mount connector, a proprietary switch bezel, or a complex compound cutout with mounting holes.

Available shape types

Circle
Round holes, LEDs, jacks
D-cut
BNC, single flat (anti-rotation)
Double D-cut
Banana socket, two parallel flats
Rectangle
IEC, HDMI, USB cutouts
Rounded rect
D-Sub, USB-C, modern connectors
Slot
Vent slots, DIN rail, adjustment slots
Hole
Mounting clearance, M3/M4/M6
Rivnut
Blind rivet nut drill hole
Compound
Any combination of above

Method A — Simple single shape

Use this when your connector needs only one cutout (a circle, rectangle, D-cut, etc.).

  1. Read the datasheet — find the panel cutout dimension
    Look for "panel cutout", "mounting hole", or "hole diameter". You need: diameter (circle), or width × height (rectangle), or diameter + flat width (D-cut).
  2. Open the Component Library Manager
    Click ⚙ Manage in the left sidebar Component Library header.
  3. Click + New Component
    Fill in: ID (unique, no spaces), Name, Category, Type (choose from the shape list above), then enter the dimensions from the datasheet.
  4. For D-cut shapes — calculate Flat Offset
    Single D-cut: flat_offset = √(r² − (chord/2)²)
    Double D-cut: flat_offset = WAF / 2
    Where r = radius, chord = flat chord width, WAF = width across flats.
  5. Click Add to Library
    The component appears immediately in the sidebar. Click + Place to drop it on the active panel.

Method B — Compound shape (cutout + mounting holes)

Use this for connectors like XLR (round body + 3 screw holes), D-Sub (rect cutout + 2 mounting holes), or IEC (rect + 2 end screws). A compound component holds multiple sub-parts at precise offsets.

  1. Read the datasheet — note ALL holes and their positions
    For each feature write down: shape (circle/rect), size, and position relative to centre (ΔX, ΔY in mm). Example for XLR-3F: main Ø24mm hole at (0,0), three M3 holes at 120° intervals on a Ø30mm bolt circle.
  2. Create a Compound component
    In ⚙ Manage → + New Component, set Type = Compound. Click Add to Library. The compound starts empty — sub-parts are added after placement.
  3. Place the compound on the panel
    Find your new compound in the sidebar. Click + Place, position it at the correct X/Y centre coordinate on the panel, click Place.
  4. Select the placed item — open the part editor
    Click the item on the canvas to select it. In the Properties panel (right sidebar) you will see the Compound Parts section with an + Add Part button.
  5. Add each sub-part
    Click + Add Part. For each part set:
    • Shape — circle, roundrect, rect, slot, D-cut, double D-cut
    • Role — cutout (main body, green), hole (mounting clearance, orange), rivnut (drill hole, blue)
    • ΔX / ΔY — offset from component centre in mm
    • Diameter or Width × Height — from the datasheet
  6. Fine-tune offsets in the Properties panel
    Each sub-part is listed with live ΔX/ΔY inputs — edit them and the canvas updates instantly. The dashed bounding circle shows the total extent of the compound.
  7. Save the layout and export DXF
    Each sub-part exports on the correct DXF layer: cutouts → CUTOUT, mounting holes → MOUNTING, rivnuts → RIVNUT. Use ⬇ DXF This Panel to export.
Tip: To reuse a compound, select it on canvas and click ⊕ Duplicate in Properties. The duplicate is independent — edit its sub-parts without affecting the original.
Tip: Built-in compound components (XLR-3F, D-Sub DB9, IEC 320 C14) are good templates — place one, select it, and study the part offsets in the Properties panel.

Keyboard & interaction reference

  • Click canvas item — select, show properties
  • Drag selected item — move on panel
  • Double-click — edit properties directly
  • Scroll wheel — zoom in/out on canvas
  • Click panel tab — switch between Front / Rear / Top / Bottom faces
  • Select tool — click to select items
  • Move tool — drag items without accidentally selecting
  • Hole tool — click canvas to place a custom drill hole
  • Rect tool — click canvas to place a custom rectangle cutout
  • Snap — toggle 1mm snap grid on/off
